## 第65课包含关系规则：初步对照结果

参考原文：
https://chanlunzhan.com/108/65

### 已对照的规则

1. 向上处理：合并后的高点、低点分别取较大值。
2. 向下处理：合并后的高点、低点分别取较小值。
3. 方向定义：当第 n 根与第 n+1 根构成包含，
   而第 n 根与第 n-1 根不构成包含时，
   若第 n 根高点 >= 第 n-1 根高点，则向上；
   若第 n 根低点 <= 第 n-1 根低点，则向下。
4. 包含关系必须按照时间顺序逐步处理。

### 尚待明确

1. 序列开头即出现包含关系时的工程处理策略。
2. 极值相同情况下，极值来源日期采用首次出现还是最后出现。
3. 使用更多原文案例验证连续包含及边界情况。

以上为初步核验，不代表全部缠论规则已验证。
