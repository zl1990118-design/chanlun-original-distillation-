# 原文导入与分段：第一阶段

## 目标
建立可追溯的原文片段，而不是直接生成交易信号。每个片段保留 PDF 页码、文本顺序、标题/日期线索、发言人类别和判定依据。

## 发言人/材料类别
- `MASTER_MAIN_TEXT`：有充分证据表明是缠师正文。
- `MASTER_REPLY`：有充分证据表明是缠师本人回复。
- `READER_QUESTION`：读者提问。
- `READER_REPLY`：其他读者回复。
- `EDITOR_OR_COMPILER`：整理者、编者说明、序言、目录说明。
- `OTHER_MATERIAL`：链接转载、附件说明或其他非目标材料。
- `SPEAKER_UNVERIFIED`：目前证据不足，不能确认发言人。

## 状态原则
- 自动识别只提供候选标签，不等于原文核验。
- 对“本 ID”“缠师”等字样不能单独作为身份判定依据。
- PDF页码是整理版页码；若有原博客链接、原始发布时间，应另行保存。
- 先保留原文，不静默改写、纠错或拼接。
- 规则候选必须引用片段 ID；读者内容只能作为问题线索，不直接成为缠师规则。

## 当前已观察到的结构（仅基于已检查页面）
- PDF第1页为封面/版本说明。
- PDF第2–7页包含整理者说明和“市场学生”署名的学习文章。
- PDF第11页开始出现《教你炒股票1》正文，带标题和时间。
- PDF第14–15页同一课程标题下还包含带独立时间的其他博文，因此不能仅凭课程标题划分文章边界。
- 目录显示系列共108课；此点来自该 PDF 的目录，不代表已核验所有页面。

## 下一阶段
1. 对完整PDF提取逐页文本，保存原始文本与页码。
2. 以标题、时间戳、署名、版面标记产生分段候选。
3. 输出 JSONL；所有自动分类初始置信度不得视作人工核验。
4. 人工抽查目录、课程正文、独立博文、留言/回复边界。
5. 再从确认属于缠师的片段中提取规则候选。
