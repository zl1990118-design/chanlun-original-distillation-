# 原文来源索引

本文件用于记录规则依据。没有完成核验的条目只作为待办，不得当作已确认引用。

## 来源记录模板

每条来源至少记录：

- 来源名称及作者/发布者
- 课程或章节标题
- 原始链接或可定位的版本信息
- 版本/发布日期（若可得）
- 页码、段落或时间戳
- 原文摘录（只记录核验所需的必要短句）
- 对应规则编号
- 核验人、核验日期
- 状态：`UNVERIFIED` / `SOURCE_CHECKED` / `CROSS_CHECKED` / `DISPUTED`

## 核验规则

1. 不凭记忆编造课程编号、标题、链接或逐字引文。
2. 如果不同版本的文字或解释不一致，分别记录，不擅自合并。
3. 二手解读只能作为辅助材料，必须与原始来源分开标注。
4. 形式化规则要指出它对应的来源位置；若是工程约定，明确标为工程约定。
